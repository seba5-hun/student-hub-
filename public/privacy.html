Privacy.

Ultimo aggiornamento: 10 ottobre 2026

MYND (prima "Student Hub") è un'app per organizzare studio, sport, sonno e progetti: impegni, voti, timer, archivio dei materiali e un coach AI. Questa pagina spiega quali dati usa e come.

Dati che salviamo

  • Account: indirizzo email e password (gestita in forma cifrata dal servizio di autenticazione Supabase). Se accedi con Google, riceviamo solo nome, indirizzo email e foto del profilo.
  • Dati di studio: impegni, voti, sessioni di studio, materie, note e impostazioni che inserisci tu.
  • Archivio: i file che carichi e il loro testo trascritto, usato dal tutor AI.
  • Chat con la Guida Studio AI.
  • Statistiche d'uso anonime: quali sezioni vengono aperte e per quanto tempo, il tipo di dispositivo. Non registriamo il contenuto di note, file o chat nelle statistiche.

I dati sono conservati su Supabase (database e spazio file) e ogni utente può vedere solo i propri.

Google Drive

Se scegli di collegare Google Drive, MYND chiede solo il permesso drive.file: può vedere, creare e modificare esclusivamente i file che carica lui nella cartella "Student Hub" del tuo Drive. Non può leggere né modificare nessun altro file del tuo Drive.

  • I file caricati restano nel tuo Google Drive e sono tuoi.
  • L'app legge anche il tuo indirizzo email Google e lo spazio usato, solo per mostrarteli nell'Archivio.
  • Il testo trascritto dei file (per il tutor AI) viene salvato in MYND.
  • L'accesso a Google resta nel tuo browser per circa un'ora; puoi revocarlo in qualsiasi momento con "Scollega" o da myaccount.google.com/permissions.

L'uso delle informazioni ricevute dalle API di Google rispetta le Google API Services User Data Policy,

Accesso con Google

Se premi "Continua con Google", Google ci comunica solo il tuo nome, il tuo indirizzo email e la foto del profilo (permessi openid, email, profile), usati per creare e riconoscere il tuo account MYND. Non riceviamo la tua password di Google.

Creazione della chiave Gemini con Google

Nella scelta dell'intelligenza artificiale puoi premere "Crea la chiave Gemini con Google" invece di crearla a mano su AI Studio. Solo in quel momento, e solo se lo confermi, MYND chiede a Google il permesso cloud-platform (gestire Google Cloud nel tuo account) e lo usa esclusivamente per:

  • trovare o creare nel tuo account un progetto Google Cloud chiamato "MYND AI", senza fatturazione;
  • attivare in quel progetto l'API Gemini (Generative Language API);
  • creare o riusare una chiave chiamata "MYND", limitata alla sola API Gemini, e leggerla.

MYND non legge, non modifica e non elimina nessun altro progetto, risorsa o dato del tuo Google Cloud, e non attiva la fatturazione. Il permesso viene usato direttamente dal tuo browser, non viene salvato sui nostri server e scade entro un'ora. La chiave creata resta salvata solo nel tuo browser. Puoi eliminare il progetto "MYND AI" in qualsiasi momento da console.cloud.google.com e revocare il permesso da myaccount.google.com/permissions.

Tutor AI (Google Gemini, Groq, ChatGPT, Claude, OpenRouter)

Quando usi la Guida Studio AI o fai leggere un file, le tue domande, le foto e il testo del materiale scelto vengono inviati al fornitore di intelligenza artificiale che hai scelto (Google Gemini, Groq, OpenAI ChatGPT, Anthropic Claude oppure OpenRouter e il modello selezionato), con la tua chiave API e direttamente dal tuo browser, per generare la risposta. Le chiavi restano salvate solo nel tuo browser. Ogni fornitore tratta i dati secondo la propria informativa; con i modelli gratuiti i dati possono essere usati per migliorare i servizi.

Uso Limitato dei dati di Google

L'uso e il trasferimento ad altre app delle informazioni ricevute dalle API di Google rispettano le Google API Services User Data Policy, inclusi i requisiti di Uso Limitato (Limited Use). I dati ricevuti da Google (account, Drive, Google Cloud) sono usati solo per le funzioni descritte sopra e visibili nell'app; non vengono venduti, non sono usati per pubblicità, non vengono letti da persone (salvo tuo consenso, per motivi di sicurezza o per obblighi di legge) e non vengono usati per addestrare modelli di intelligenza artificiale.

Cosa non facciamo

  • Non vendiamo né cediamo i tuoi dati a terzi.
  • Non mostriamo pubblicità.

I tuoi diritti

Puoi esportare i tuoi dati dal menu dell'app, modificarli o cancellarli in qualsiasi momento. Per chiedere la cancellazione completa dell'account o per qualsiasi domanda scrivi a flowbase.service@gmail.com.

Google user data — English summary

MYND requests Google user data only for features the user starts: Sign in with Google (openid, email, profile: to create and identify the account), Google Drive (drive.file: only files MYND itself uploads, in the "Student Hub" folder) and Create Gemini key with Google (cloud-platform: only to find or create a project named "MYND AI" without billing in the user's own account, enable the Gemini API in it, and create or read one API key named "MYND" restricted to the Gemini API). MYND does not read, change or delete any other Google Cloud project or resource and never enables billing. Access tokens are used in the user's browser, are never stored on our servers and expire within one hour; the API key is kept only in the user's browser. MYND's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold, not used for advertising, not read by humans (except with the user's consent, for security or legal reasons) and not used to train AI models. Users can revoke access at myaccount.google.com/permissions and request deletion of their data at flowbase.service@gmail.com.
